# 마키타 18V 배터리 기반 IoT 센서용 스마트 전원공급 타이머 기술 제안서
(Smart Power Supply Timer for IoT Sensors using Makita 18V Battery Dock)

## 1. 프로젝트 개요 및 배경 (Background & Objectives)

본 제안서는 AliExpress에서 확보한 **마키타 18V 배터리 DIY 전원 인출 도크 어댑터**와 대용량(5.0Ah/6.0Ah, 약 90~108Wh) 마키타 호환 리튬이온 배터리를 에너지원으로 활용하여, 전력망이 없는 야외, 비닐하우스, 농장, 건설 현장, 스마트 팩토리 등에서 **IoT 센서 노드에 설정된 시각 또는 주기(Interval)에 맞춰 지능적으로 전원을 공급/차단하는 초저전력 스마트 타이머 시스템**의 하드웨어 및 임베디드 아키텍처를 정의합니다.

### 1.1 핵심 개발 목표
1. **마키타 18V LXT 슬라이드 배터리 인터페이스 결합**: 도크 어댑터의 4개 마운팅 홀을 활용한 일체형 컴팩트 모듈 설계.
2. **초저 대기 전력 (Nano/Micro-power Standby)**: IoT 센서가 꺼져 있는 비가동(OFF) 상태에서 시스템 자체 대기 전력 소모를 **$20\ \mu\text{A}$ 이하**로 억제하여 수개월~1년 이상 장기 운용 보장.
3. **15.0V 하드웨어 과방전 차단 (LVD)**: 배터리 전압이 방전 종지 전압(15.0V)에 도달하면 무조건 전체 회로를 물리적으로 영구 래치 차단하여 배터리 사망 방지.
4. **스마트 스케줄링 및 사용자 편의성 (Smart UX)**: 스마트폰(BLE/Web) 또는 로컬 인터페이스를 통해 간편하게 급전 주기(예: 매 1시간마다 3분 작동) 및 실시간 시계 기반 스케줄(예: 매일 08:00, 18:00 정시 급전) 설정.
5. **다중 출력 전압 지원 (3.3V / 5V / 12V / 18V)**: 범용 센서(토양 수분, 기상 센서, 카메라, 가스 감지기 등) 및 통신 모듈(LTE-M, LoRa, Wi-Fi)에 최적화된 전원 레일 공급.

## 3. 핵심 기술 과제 및 엔지니어링 솔루션

### 3.1 [핵심 과제 1] 극저 대기 전류 설계 (Ultra-Low Quiescent Standby)
일반적인 전원 회로를 18V 배터리에 상시 연결해 둘 경우, 벅 컨버터와 MCU의 대기 전류(약 15~30mA)만으로도 **한 달에 약 10~20Wh 이상이 소모**되어 센서를 켜지도 않고 배터리가 방전됩니다.

* **엔지니어링 솔루션**: **2단계 전원 분리 구조 (Power Gating Architecture)**
  1. **상시 전원단(Always-ON Domain)**: 
     - 초저 대기전류 LDO(예: **TI TPS7A02**, 대기전류 **$25\ \text{nA}$**)를 통해 RTC와 타이머 제어 회로에만 미세 전력 공급.
     - 대기 시 전체 시스템 소비 전류: **$< 15\ \mu\text{A}$** 달성 (5.0Ah 배터리 기준 대기 시간 **약 38년 분량**으로 자가방전 수준 이하).
  2. **가동 전원단(Switched Load Domain)**:
     - 고효율 벅 컨버터 및 센서 부하는 **P-MOSFET 하이사이드 스위치 후단에 배치**.
     - 설정된 가동 시각이 되기 전까지는 벅 컨버터로 들어가는 18V 입력 전원 자체가 **완전히 물리적으로 단선(0mA)**되어 누설 전류 차단.

---

### 3.2 [핵심 과제 2] 15.0V 독립 저전압 차단 (Hardware LVD)
호환 배터리 및 도크 어댑터에는 과방전 차단 회로가 없으므로, IoT 센서가 켜진 상태에서 배터리가 소진되면 0V까지 떨어져 배터리가 영구 파손됩니다.

* **엔지니어링 솔루션**: **하드웨어 히스테리시스 전압 비교기**
  - **구성**: 마이크로파워 전압 콤퍼레이터(예: **TLV3691**, 동작 전류 $75\ \text{nA}$) 또는 전압 감시 IC + 정밀 전압 분배 회로.
  - **동작 로직**:
    - 배터리 전압이 **$15.0\text{V}$ ($3.0\text{V}/\text{cell}$)** 이하로 떨어지면, P-MOSFET 게이트 드라이버 신호를 강제로 LOW로 고정(Latch-off).
    - 충전된 배터리(최소 **$16.5\text{V}$ 이상**)가 체결되기 전까지는 타이머가 동작해도 부하 전원을 절대 켜지 않음.
    - 배터리 전압을 분압하여 MCU ADC 핀으로 전달, 잔량(%)을 실시간 계측.

---

### 3.3 [핵심 과제 3] 스마트 시간 설정 인터페이스 (Smart UX & Scheduling)

| 구분 | 방안 A: BLE 스마트폰 웹 앱 제어 (권장) | 방안 B: 로컬 OLED + 로터리 엔코더 | 방안 C: 하드웨어 나노 타이머 (TPL5110) |
| :--- | :--- | :--- | :--- |
| **제어 MCU / IC** | **ESP32-C3** (RISC-V, BLE 5.0) | **RP2040** 또는 **ATmega328P** | **TI TPL5110** (순수 아날로그 IC) |
| **설정 방식** | 스마트폰 블루투스(BLE) 또는 Web BLE로 접속하여 직관적 스케줄링 UI 제공 | 기기 본체의 0.96" OLED 화면을 보며 다이얼로 시간/주기 설정 | 기판의 DIP 스위치 또는 정밀 가변저항(Potentiometer) 조절 |
| **스케줄 기능** | • 매일 특정 시각(예: 09:00, 18:00)<br>• 반복 주기(예: 30분마다 2분 동작)<br>• 요일별/센서별 맞춤 설정 | • 단순 반복 주기 설정 (5분/15분/1시간/6시간/24시간)<br>• 가동 시간 (10초~30분) | • 단순 주기적 타이머 (100ms ~ 2시간 반복 트리거) |
| **대기 전류** | 딥슬립 시 **약 $5\ \mu\text{A}$** | 슬립 모드 시 **약 $15\ \mu\text{A}$** | **$35\ \text{nA}$** (극도로 낮음) |
| **특징 및 장단점** | • 폰으로 배터리 전압/상태 확인 가능<br>• 밀폐 방수 케이스 내부 설치 가능 | • 스마트폰 불필요, 현장 즉시 조작<br>• 케이스 가공 및 방수 실링 필요 | • 코딩 불필요, 초단순 하드웨어<br>• 정밀한 실시간 시계 스케줄 불가 |

> 🌟 **강력 추천: [방안 A] BLE 기반 스마트 하이브리드 제어기**  
> 사용자가 현장에서 배터리 팩을 교체할 때 스마트폰으로 블루투스 연결만 하면, 전용 앱 설치 없이도 웹 브라우저(Web Bluetooth API)를 통해 **현재 배터리 전압, 과거 가동 로그, 요일별/시간대별 전원 공급 스케줄**을 손쉽게 설정할 수 있습니다.

### 3.4 [핵심 과제 4] 고효율 다중 전원 출력단 (Power Stage)
18V~21V의 높은 전압을 IoT 센서 동작 전압으로 변환할 때 발열을 최소화하고 변환 효율을 극대화해야 합니다.

* **메인 DC-DC 컨버터**:
  - **IC 후보**: TI TPS54302 (입력 4.5~28V, 출력 5V/3A, 동기식 벅, 효율 최대 95%)
  - **3.3V 레일**: 5V 레일 후단에 LDO(AMS1117-3.3 또는 RT9013) 또는 소형 벅 배치.
  - **12V 옵션**: 산업용 센서/솔레노이드 밸브 구동용 12V 1.5A 동기식 벅 컨버터 추가 구성 가능.
  - **직결 18V 스위칭 출력**: P-MOSFET을 거친 18V 고출력 전원을 그대로 인출하는 보조 터미널 지원 (고출력 펌프/모터 구동용).

## 4. 추천 하드웨어 회로 구성 (Schematic Architecture)

### 4.1 하이사이드 P-MOSFET 스위칭 회로 예시
```
    +18V (Batt via LVD)
         │
         ├───[ 100kΩ ]───┐
         │               │
     [ Source ]          │
   ┌─────┴─────┐         │
   │  P-MOSFET │         │
   │ (AO4407A) ├──[Gate]─┼───[ 10kΩ ]─── Collector
   └─────┬─────┘                        [ NPN Transistor (2N3904) ]
     [ Drain ]                            Base ──[ 4.7kΩ ]──◀ MCU Trigger Pin
         │                               Emitter ── GND
         ▼
    +18V Switched Output
  (To DC-DC Buck Converter)
```
- MCU의 일반 GPIO 신호(HIGH: 3.3V)로 2N3904를 턴온시키면 P-MOSFET의 게이트 전압이 접지로 떨어져 MOSFET이 포화 도통(ON), 부하단으로 18V 대전류가 무손실 공급됩니다.
- MCU가 GPIO를 LOW로 내리거나 슬립에 들어가면 풀업 저항(100kΩ)에 의해 게이트가 소스와 동전위가 되어 완전히 OFF(누설전류 0.1µA 미만)됩니다.

### 4.2 인터럽트 기반 딥슬립 및 자동 셧다운 루프
1. **슬립 상태 (Standby)**: MCU와 센서 전원은 완전히 꺼져 있거나 MCU가 극저전력 딥슬립(5µA) 유지.
2. **알람 기상 (Wake-up)**: RTC 칩의 INT 핀이 사전 설정된 시각(예: 12:00:00)에 LOW 인터럽트 펄스 발생 ➡️ 하이사이드 스위치 도통.
3. **센서 가동 (Active Work)**: DC-DC 벅 컨버터 가동 ➡️ 5V/3.3V 안정화 ➡️ 센서 계측 및 무선 데이터 전송 (약 10~30초 소요).
4. **작업 완료 후 전원 차단 (Self Power-Down)**: IoT 센서 작업이 끝나면 MCU가 "Done" 신호를 보내 하이사이드 스위치를 자체 차단(Self-latch OFF)하고 다음 알람 시간까지 나노 전력 대기 상태로 복귀.

## 5. 단계별 개발 로드맵 (Development Roadmap)

### Phase 1: PoC (개념 검증) 브레드보드 프로토타이핑 (1~2주)
- **부품 구성**:
  - 알리 도크 어댑터 + 마키타 배터리
  - 15.0V LVD 릴레이 모듈 (XH-M609 완제품 활용)
  - ESP32-C3 개발보드 + DS3231 RTC 모듈 + P-MOSFET 스위칭 모듈
  - 5V 3A 강압 벅 모듈
- **검증 항목**:
  - 시간 설정에 따른 정밀 ON/OFF 스위칭 동작 검증
  - 대기 시 총 소비 전류(멀티미터 mA/µA 단위) 실측
  - 배터리 15.0V 저전압 도달 시 정상 차단 여부 테스트

### Phase 2: 전용 PCB 회로 설계 및 통합 (2~3주)
- **작업 내용**:
  - EasyEDA 또는 KiCad를 이용한 일체형 단일 보드(SMD) 회로 설계
  - LVD 회로, 초저전력 LDO, DS3231 RTC, ESP32-C3, TPS54302 벅 컨버터, P-MOSFET 원칩 통합
  - PCB 주문 (JLCPCB 등 SMT 서비스 활용)

### Phase 3: 3D 프린팅 기구 결합 및 외장 케이스 제작 (1주)
- **작업 내용**:
  - 알리 도크 어댑터의 **4개 마운팅 홀 (가로 31mm, 세로 39.3mm)**과 결합되는 전용 하우징 설계
  - 배터리 위에 모자(Cap)처럼 얹혀지는 일체형 콤팩트 폼팩터 구현
  - 외부 인터페이스: 5V USB-A 포트, 방수 항공 단자(GX12 또는 스크루 터미널), 상태 표시 LED, 비상 수동 ON 토글 스위치 장착

## 6. 결론 및 다음 단계 제안 (Recommendations)

마키타 18V 배터리 도크 어댑터를 활용한 IoT 스마트 전원 타이머는 **"풍부한 배터리 용량(100Wh)"**과 **"초저전력 파워 게이팅 회로"**가 결합될 경우, 일반 배터리로는 불가능했던 **수개월~1년 이상의 완전 무전원 야외 IoT 시스템**을 구축할 수 있는 매우 실용적인 고부가가치 프로젝트입니다.

### 🎯 사용자 피드백 요청 및 의사결정 사항
1. **타이머 설정 방식 선정**:
   - [추천] **스마트폰 BLE/웹 연동형 (ESP32-C3 기반)** vs **기기 본체 버튼/스크린형 (OLED/로터리)**
2. **연결할 IoT 센서의 사양**:
   - 센서의 동작 전압(3.3V / 5V / 12V) 및 1회 가동 시 요구되는 동작 시간(예: 30초 측정 후 종료 / 10분간 연속 작동)
3. **우선 진행 단계**:
   - 시중 모듈(ESP32 + RTC + 릴레이/FET 모듈)을 이용한 **빠른 1차 프로토타입 제작 가이드** 수립 여부
